# Support

Questions, bug reports, and feature requests should be submitted through the
[GitHub issue tracker](https://github.com/Thadhaeg/Partial-association-explorer/issues).

Before opening an issue:

1. Check the README and the guides in `docs/guides/`.
2. Search existing issues for the same problem.
3. Confirm that the problem occurs with the current version of the repository.

For a bug report, include the R version, operating system, relevant package
versions, a minimal reproducible dataset when licensing permits, and the steps
needed to reproduce the behavior. Remove personal or confidential information
before attaching data.

The maintainers provide support on a best-effort basis. Security or privacy
concerns that should not be disclosed publicly should be sent privately to the
corresponding author listed in the paper.
