# Example data

This directory contains a compact, analysis-ready Belgian extract adapted from
European Social Survey (ESS) Round 11 and a two-column variable-description
file. The extract is included to make the application's examples and
screenshots reproducible; it is not an official ESS release or a replacement
for data obtained from the ESS Data Portal.

## Files

- `ESS11_BE_data.csv`: analysis data used by the examples and screenshots.
- `ESS11_BE_description.csv`: variable names and human-readable descriptions.

## Provenance and citation

The source cited for this project is the ESS11 Integrated File, Edition 3.0.
The repository extract is limited to Belgian respondents and the variables
needed for the examples. Users conducting substantive research should obtain
the current official data directly from the
[ESS Data Portal](https://ess.sikt.no/en/study/412db4fe-c77a-4e98-8ea4-6c19007f551b)
and consult its documentation and weighting guidance.

Suggested source citation:

> European Social Survey European Research Infrastructure. ESS11 Integrated
> File, Edition 3.0. Sikt - Norwegian Agency for Shared Services in Education
> and Research. https://doi.org/10.21338/ess11e03_0

When referring specifically to the repository file, identify it as adapted
from ESS Round 11, Edition 3.0. Analyses and interpretations are the
responsibility of the repository authors, not ESS ERIC or Sikt.
